# Steward icon

Steward uses an inventory tray containing three item blocks beneath a check mark. Its plugin logo was newly generated in the existing plugin family's flat cyan-to-magenta style, with a charcoal background and matching gradient border. The approved ExpandedHotbars utility icon supplies the subject; AutoRetainer's plugin icon supplies the branding style.

The logo was created with built-in image generation and exported to `assets/icon.png` at 512 by 512. Its prompt and reference roles are recorded in `assets/icon.prompt.json`. The hotbar artwork remains its separately approved rendering.

The installer feed uses this asset through its existing `IconUrl`, and release packages include it as `images/icon.png`. Steward's name, internal identity and commands are unchanged.
