# Steward icon

Steward uses an inventory tray containing three item blocks beneath a check mark. The cyan-to-magenta emblem and quiet indigo background match its approved ExpandedHotbars utility icon, while giving Steward a different symbol from AutoRetainer's bell.

The artwork was created with built-in image generation for the hotbar icon set. The installer asset, `assets/icon.png`, is a 512 by 512 export of that approved image; no new artwork was generated for this export. The original generation prompt is recorded in `assets/icon.prompt.json`.

The installer feed uses this asset through its existing `IconUrl`, and release packages include it as `images/icon.png`. Steward's name, internal identity and commands are unchanged.
