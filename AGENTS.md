# Steward

Companion owns classification, collection references, sale rules and market coordination. AutoRetainer owns existing disposal and storage workflows. Preserve other plugins' configurations; import read-only. Default dry-run. Exact item IDs, dyes ignored, both native plates and Glamaholic, level-one glamour gear, blues and special/unknown acquisition sources preserved until collected. Confirm exact collected copies before surplus disposal. Unknown is never zero or absent. User exclusions override all handling. Keep native acceptance distinct from automated validation.
